# ait-dividends-data

배당체질(DividendDNA) 미니앱이 읽는 분배 구간 데이터입니다.

## 담고 있는 것

`quotes.json` 은 종목별로 아래 파생 지표만 담습니다.

| 필드 | 뜻 |
|---|---|
| `yieldBand` | 분배율 구간 — `very-high`(10% 이상) / `high`(5~10%) / `mid`(3~5%) / `low`(3% 미만) |
| `stability` | 분배 안정성 — `stable` / `variable` / `null`(판정 불가) |
| `trend` | 최근 12개월 상대 추이 (최대값 100 기준 정규화, 금액 단위 없음) |
| `currency` | 분배 통화 |
| `disclosureUrl` | 해당 종목의 운용사·IR 공시 페이지 |

## 담지 않는 것

주당 배당금, 현재가, 순자산, TTM 분배금 합계 같은 **원본 수치는 담지 않습니다.**
정확한 금액은 각 종목의 `disclosureUrl` 에서 확인하세요.

## 갱신

매주 월요일 오전 6시(KST) 자동 갱신됩니다.
수집 과정에서 이상치가 발견되면 발행을 중단하고 직전 데이터를 유지합니다.
낡은 값이 틀린 값보다 낫다는 판단입니다.
